# 06 划船渡河（冥想合作小遊戲）

2 / 4 / 6 位玩家各用自己的手機上船，**按住 = 吐氣・划槳，放開 = 吸氣・回槳**，
跟著呼吸圈一起划，把小船划向彼岸。零依賴，只需要 Node.js 18+。

## 啟動
```bash
npm start            # 預設 http://localhost:3000，終端機會印出區網網址
PORT=8080 npm start  # 換埠號
```
同一個 Wi-Fi 的手機開終端機顯示的網址即可。跨網路遊玩需部署到支援 WebSocket 的主機（Render、Railway、Fly.io、VPS 等）。

## 四種航線（船長在大廳選擇）
| 航線 | 呼吸節拍 | 容錯 | 節拍引導 | 水流 | 約需時間 |
|---|---|---|---|---|---|
| 第一次練習 | 7 秒，最慢 | 最寬 | 全程顯示＋新手提示 | 無 | 1 分鐘 |
| 簡單 | 6.5 秒 | 寬 | 後段才淡出 | 微弱 | 1.5 分鐘 |
| 普通 | 6 秒 | 中 | 中途漸隱 | 輕微 | 2 分鐘 |
| 困難 | 5 秒 | 小 | 很早就隱去 | 強，會讓船偏航 | 3 分鐘 |

水流推船偏航時，畫面會提示「哪一舷休息一槳」，全隊要一起判斷與配合。

## 遊戲中的控制
- ☰ 選單（右上角）：
  - **船長**：點選單＝全隊暫停；可繼續、重新開始（同航線）、回大廳換航線。
  - **其他船員**：可「請船長暫停」，或「離開船隊」（離開後由幻影槳手代划，不影響其他人）。
  - 重新開始、回大廳、離開都要按兩次確認，避免誤觸。
- 底部四顆按鈕：無聲提示（準備好了／慢一點／一起／穩住）。

## 畫面與全螢幕
- 畫面會依螢幕寬高自動縮放，整艘船（2/4/6 人）一定完整顯示；手機、平板、電腦都適用。
- 右上角 ⛶ 按鈕＝全螢幕（Android／電腦瀏覽器）。**iPhone Safari 不支援網頁全螢幕**：點「分享」→「加入主畫面」，之後從主畫面圖示開啟就是全螢幕。
- 遊戲中會要求螢幕保持常亮，避免冥想時手機自動熄屏而斷線。

## 參數
`server.js` 最上方的 `MODES` 可調整每種航線的節拍、容錯、水流與長度；`RATE_SCALE=6 npm start` 可加速測試。
