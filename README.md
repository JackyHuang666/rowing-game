# 06 划船渡河（冥想合作小遊戲）

2 / 4 / 6 位玩家各用自己的手機上船，**按住 = 吐氣・划槳，放開 = 吸氣・回槳**，
跟著呼吸圈一起划，把小船划向彼岸。零依賴，只需要 Node.js 18+。

## 啟動
```bash
npm start            # 預設 http://localhost:3000，終端機會印出區網網址
PORT=8080 npm start  # 換埠號
```
同一個 Wi-Fi 的手機開終端機顯示的網址即可。要跨網路遊玩，請部署到支援 WebSocket 的主機
（Render、Railway、Fly.io、自己的 VPS 皆可，需 HTTPS 時瀏覽器會自動改用 wss）。

## 玩法
1. 一人「建立船隊」並選 2/4/6 人，其他人輸入 4 位數代碼（或點邀請連結）加入。
2. 船長按「出發」（人數未滿時可用「加入示範夥伴」試玩）。
3. 開場有 8 秒呼吸引導，之後每 6 秒一個循環：前半吐氣划槳、後半吸氣回槳。
4. 節拍引導隨航程漸漸淡出，後半段靠看夥伴的槳與默契。
5. 偶數座位在左舷、奇數在右舷；左右用力不均船會偏航。
6. 回槳時誤按會「濺起水花」，降低平靜分數。
7. 底部四顆按鈕可傳送無聲提示：準備好了／慢一點／一起／穩住。
8. 抵達彼岸後顯示 節奏、同心、平靜 三項結果。

## 調整參數（server.js 最上方）
`T` 呼吸週期秒數、`INTRO` 開場引導、`MAX_TIME` 最長航行、`RATE` 船速（也可用環境變數 `RATE=8` 快速測試）。
斷線的玩家會由「幻影槳手」暫代，重新連線後自動接回。
